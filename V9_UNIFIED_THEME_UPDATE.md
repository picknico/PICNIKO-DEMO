# PICNIKO V9 — Unified Theme Update

## Visual direction

PICNIKO now uses a consistent **premium light theme** for public-facing modules:

- Purple + cyan brand identity
- Bright, readable surfaces
- Soft borders and restrained shadows
- Rounded cards and consistent spacing
- One visual language for buttons, cards, lists, navigation and forms
- Mobile-first responsive behavior
- Focus-visible accessibility outlines

Reels and Messages can retain their **immersive dark content canvas** where it improves video/chat readability, while their surrounding controls continue to use the same PICNIKO brand tokens.

## Scope

This is a visual-system update only. It does not:

- modify Supabase tables or policies;
- change QR scan or reward logic;
- add service-role credentials;
- perform Git commit or push;
- claim that demo UI actions are production backend actions.
