# PICNIKO V8 Full Build

This package is rebuilt from the verified V4 modular archive and includes all existing modules plus Education & R&D, Company Portal, Partner Portal and Database Status pages.

## Open
1. Extract the ZIP.
2. Open the extracted root folder in VS Code.
3. Run the root `index.html` with Live Server.
4. Do not open a missing deep URL manually; navigate from Home.

## Important
- This is a modular UI and integration foundation, not a claim of production completion.
- No destructive SQL is included or executed.
- QR/reward protected baseline is preserved.
- Never place service-role keys in frontend files.
